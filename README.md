# Primitive DB

`Primitive DB` — учебная консольная база данных на Python. Программа позволяет
создавать таблицы и выполнять основные CRUD-операции с данными.

Информация о таблицах и их столбцах сохраняется в файле `db_meta.json`. Записи
каждой таблицы хранятся в отдельном JSON-файле в директории `data/`. Поэтому
таблицы и их данные остаются доступными после перезапуска программы.

## Установка

Для работы необходимы Python 3.12 или новее и пакетный менеджер `uv`.

Установите зависимости проекта:

```bash
uv sync
```

## Запуск

Запустите базу данных командой:

```bash
uv run database
```

После сборки пакет можно установить как консольный инструмент:

```bash
uv tool install --force dist/primitive_db-0.1.0-py3-none-any.whl
database
```

## Управление таблицами

Программа поддерживает следующие команды:

```text
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
list_tables
drop_table <имя_таблицы>
help
exit
```

Доступные типы данных:

- `int` — целое число;
- `str` — строка;
- `bool` — логическое значение.

При создании таблицы программа автоматически добавляет столбец `ID:int`.

## CRUD-операции

### Добавление записи

```text
insert into <имя_таблицы> values (<значение1>, <значение2>, ...)
```

Столбец `ID` указывать не нужно: программа создаёт его автоматически. Строковые
значения необходимо заключать в двойные кавычки.

Пример:

```text
insert into users values ("Sergei", 28, true)
```

### Чтение записей

Получить все записи:

```text
select from users
```

Получить записи по условию:

```text
select from users where age = 28
```

### Обновление записей

```text
update users set age = 29 where name = "Sergei"
```

### Удаление записей

```text
delete from users where ID = 1
```

### Информация о таблице

```text
info users
```

Команда показывает структуру таблицы и количество записей.

## Декораторы и замыкания

Модуль `src/primitive_db/decorators.py` содержит три декоратора и функцию
для создания кэша:

- `handle_db_errors` обрабатывает `KeyError`, `ValueError` и
  `FileNotFoundError`. Ошибка выводится в консоль, после чего можно ввести
  следующую команду. При ошибке результат операции не сохраняется.
- `confirm_action(action_name)` запрашивает подтверждение перед `drop_table`
  и `delete`. Для подтверждения введите `y`. Любой другой ответ отменяет действие.
- `log_time` измеряет время выполнения `insert` и `select` с помощью
  `time.monotonic()`. Например:
  `Функция select выполнилась за 0.001 секунд`.
- `create_cacher()` возвращает функцию `cache_result(key, value_func)`.
  Словарь кэша хранится в замыкании. Повторная выборка той же таблицы с тем же
  условием берётся из кэша: `Результат взят из кэша.`

После успешного изменения таблиц или записей кэш сбрасывается. Он действует
в рамках одного запуска программы и учитывает изменения через её команды.
При ручном изменении JSON-файлов перезапустите программу.

Пример отмены удаления:

```text
Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: n
Операция отменена.
```

Все декораторы используют `functools.wraps`, сохраняя имена обёрнутых функций.
`None` означает ошибку или отмену, а пустой список `[]` является корректным
результатом. Благодаря этому отменённое действие не записывает `null` в JSON.
