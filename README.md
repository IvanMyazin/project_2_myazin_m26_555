# Primitive DB

`Primitive DB` — учебная консольная база данных на Python. Программа позволяет
создавать и удалять таблицы, а также просматривать список существующих таблиц.

Информация о таблицах и их столбцах сохраняется в файле `db_meta.json`. Поэтому
созданные таблицы остаются доступными после перезапуска программы.

## Установка

Для работы необходимы Python 3.12 или новее и пакетный менеджер `uv`.

Установите зависимости проекта:

```bash
uv sync
```

## Запуск

Запустите базу данных командой:

```bash
uv run database
```

## Управление таблицами

Программа поддерживает следующие команды:

```text
create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...
list_tables
drop_table <имя_таблицы>
help
exit
```

Доступные типы данных:

- `int` — целое число;
- `str` — строка;
- `bool` — логическое значение.

При создании таблицы программа автоматически добавляет столбец `ID:int`.

## Пример использования

```text
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Введите команду: list_tables
- users

Введите команду: drop_table users
Таблица "users" успешно удалена.

Введите команду: exit
Выход из программы
```

## Проверка кода

